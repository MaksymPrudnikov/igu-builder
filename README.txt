IGU Builder — GitHub Pages package

UPLOAD TO GITHUB
1. Upload the CONTENTS of this folder to the root of your repository.
2. Keep data/db.json inside the data folder.
3. GitHub repository -> Settings -> Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: /(root), Save.
6. Open the GitHub Pages URL.

USAGE
- index.html: start page
- igu-form.html: IGU Builder
- admin.html: Catalog / Admin
- Admin password: IGU2026!

IMPORTANT
The Builder contains the full working embedded catalog and functions without Admin login or db.json.
Admin is optional. It edits an override saved in this browser's localStorage.
Changes saved in Admin affect the Builder on the same browser/origin.
Use Export JSON in Admin to back up changes.
To make an edited catalog the default for everyone, replace data/db.json in GitHub with the exported JSON.

DATABASE INCLUDED
- 340 glass catalog items
- 154 substrates
- 39 coatings
- 686 laminated glass records
- spacers / spacer sizes / gases / sealants / interlayers / paints / heat treatments / frit settings / technical constants
- Pilkington Energy Advantage C, Energy Advantage Low-E, Energy Advantage OW classified as Low-E
